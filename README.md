# Mars

This is the subrepository for Berryman's SCM + Voigt. If you want to get the results, run the run.py file. You are more than welcome to modify some of the parameters in here.

The case with $v_p = 4.1\,\mathrm{km/s}$ corresponds to the example presented in Wright et al. (2024).

For reference, we have included images of the implementation results from the original study:

- **`impl1.png`**: Results obtained using a density constraint of  
  $2537 \pm 167\,\mathrm{kg/m^3}$

- **`impl2.png`**: Results obtained using a density constraint of  
  $2589 \pm 157\,\mathrm{kg/m^3}$

These figures are included to document the sensitivity of the results to the assumed density constraint and to reflect values reported in different parts of the original study, based on both the published paper and the accompanying MATLAB implementation.
